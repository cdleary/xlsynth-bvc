Download all and seed a cache

Run from a checkout of xlsynth-bvc. The destination must be new and outside the checkout. The command verifies every archive, reconstructs the input paths, and creates reusable IR-import roots in the named cache.

cargo run --release --bin xlsynth_bvc -- \
  --store-dir ../ir-cache/artifacts --artifacts-via-sled ../ir-cache/artifacts.sled \
  import-ir-archives \
  --url SITE_URL \
  --out-dir ../downloaded-corpus

Publication root: SITE_URL. With JavaScript disabled, replace SITE_URL with this page’s parent directory URL (remove ir/ or ir/index.html). For reproducible downloads, use an immutable /sites/SITE_ID/ URL.

Inputs are written to ../downloaded-corpus/inputs/<corpus>/. Imports validate content hashes and selected top functions. They do not download evaluation results or run synthesis. Downstream cache hits also require matching tools and options.
