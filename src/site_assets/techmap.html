Measurement method and coverage

ABC’s area-only mapping uses map -a. Its default map is timing-oriented and includes area recovery; these runs do not set an explicit delay target with -D.

g8r’s area and delay objectives are separate implementations. The connecting line indicates the measured choices; it does not imply that intermediate implementations were measured. A point is dominated only when another measured implementation has no larger area or delay and is strictly better on at least one.

The overview divides each input’s area and delay by the selected ABC implementation for that same input. Inputs with a missing or zero reference measurement remain in the numeric table and are excluded from ratios. Coverage counts describe this release and cohort only. These fixed cohorts can overlap with the full corpus and with each other.

Delay is a comparative library timing estimate, before placement or routing.
